### 🍷 About me

I’m a data engineer in **Istanbul** with **9+ years** across information systems, data warehousing and business intelligence, mostly in pharmaceutical distribution and construction.

I build **ETL pipelines in SQL Server and Python**, model data into **star schemas**, and deliver **Power BI dashboards** that management uses to track KPIs. I also care about the unglamorous parts: access control, backups, data quality and queries that stay fast.
